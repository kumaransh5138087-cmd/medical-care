# MediCare Hospital Management System

A full-stack starter HMS built with React/Vite, Node/Express and MongoDB.

## Run
1. Install Node.js 18+ and MongoDB.
2. Copy `server/.env.example` to `server/.env`.
3. From the project root:
   `npm install`
   `npm run install:all`
   `npm run seed`
   `npm run dev`
4. Open the Vite URL shown in the terminal.

## Included
Authentication, RBAC foundation, patients, doctors, appointments, MongoDB models, seed data and a responsive admin dashboard. The architecture is ready to extend with EMR, pharmacy, lab, billing and IPD modules.
